# Index of Bessarabian parish registers (ANRM fond 211)

Parish registers of Bessarabia (births, marriages, deaths), 1810-1931, held in fond 211 of the National Archives of the Republic of Moldova: from a village name to the archival file and to its images on FamilySearch.

Site: https://index-moldova-parish-registers.github.io/ (English, Română, Français, Русский, Українська)

Sister site, for the poll tax censuses (revision lists): https://index-moldova-revision-lists.github.io/

Data: `fonds211.json`. Everything here is released under CC0 1.0 (see LICENSE). No archive image is hosted.
